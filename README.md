simple Python-based Weather Application that fetches real-time weather information using the OpenWeatherMap API. Users can enter a city name and get details such as temperature, humidity, weather conditions, and wind speed.

Features

Get current weather information for any city
Displays:
Temperature (°C)
Humidity (%)
Weather Condition
Wind Speed (m/s)
City and Country
Error handling for:
Invalid city names
Network issues
API timeouts
Missing API key
Uses OpenWeatherMap API for accurate weather data

Technologies Used
Python 3
Requests Library
OpenWeatherMap API
